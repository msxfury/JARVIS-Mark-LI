# Security Policy

## Supported Versions

This project currently supports the latest repository version.

## Reporting a Vulnerability

Please report suspected security issues privately by opening a GitHub Security Advisory or contacting the maintainer directly. Do not disclose vulnerabilities publicly until they have been addressed.

## Secret Handling

- Do not commit API keys, tokens, or other secrets.
- Keep local secrets in environment variables or local-only configuration files.
- Ensure any exposed credentials are rotated immediately.
